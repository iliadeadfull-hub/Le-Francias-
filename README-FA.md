# Le Français — نسخهٔ PWA

این پوشه یک PWA کامل است: `index.html` (خود برنامه)، `manifest.webmanifest`، `sw.js` (کار آفلاین) و `icons/`.

## نصب روی هاست (رایگان)
1. این پوشه رو (نه فقط یک فایل) روی یک هاست **HTTPS** بذار. ساده‌ترین‌ها: Netlify Drop (`app.netlify.com/drop`)، Cloudflare Pages، یا GitHub Pages.
2. آدرس رو بدون VPN و با اینترنت معمولی باز کن و مطمئن شو درست باز می‌شه.
3. PWA فقط روی HTTPS (یا localhost) کار می‌کنه؛ با باز کردن مستقیم فایل (`file://`) یا از داخل لینک Claude کار نمی‌کنه.

## نصب روی گوشی کاربر
- اندروید (Chrome): منوی ⋮ ← «Install app» یا «Add to Home screen».
- آیفون (Safari): دکمهٔ Share ← «Add to Home Screen».
بعد از اولین بار باز شدن با اینترنت، برنامه آفلاین هم کار می‌کنه.

## آپدیت
پوشهٔ جدید رو دوباره روی همون هاست آپلود کن. اسم کش با هر نسخه خودکار عوض می‌شه و کاربر دفعهٔ بعدی که برنامه رو باز کنه (و بعد یک بار دیگه) نسخهٔ جدید رو می‌بینه.

## نکته دربارهٔ پیشرفت
پیشرفت داخل مرورگر ذخیره می‌شه و برای هر آدرس جداست. روی بعضی گوشی‌ها (به‌خصوص آیفون) برنامهٔ نصب‌شده با Safari حافظهٔ مشترک ندارد. قبل از نصب، از «💾 پشتیبان پیشرفت» استفاده کن و بعد از نصب بازیابی کن.
